# Security policy

## Sensitive information

Examples and labs must use fictional data. Do not attach real configuration exports, logs, assessment reports, credentials, internal hostnames, subscription IDs, tenant IDs, or customer information to public issues or pull requests.

## Reporting a vulnerability

Use the repository's private security-reporting option for vulnerabilities. Include affected leaf IDs, sanitized reproduction steps, impact, and mitigation. Do not publish exploitable details before a fix is available.

## Operational safety

Material in this repository is educational. Review current vendor guidance and test through normal lab, peer-review, and change-control processes before production use.
